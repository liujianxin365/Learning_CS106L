# Learning Method

## Workflow

1. Read the original slide deck.
2. Write down confusing points before asking for help.
3. Ask for explanations with a page number, screenshot, or copied code.
4. Convert the answer into my own words in `lectures/`.
5. Add a tiny C++ experiment when a concept feels abstract.
6. Mark the review checklist only when I can explain the idea without looking.

## Note Style

- Prefer short explanations over copied slide text.
- Keep both English technical terms and Chinese explanations.
- Record mistakes and misunderstandings explicitly.
- Put code experiments in `experiments/`, not inside lecture notes.

## Commit Style

Examples:

```text
docs: initialize CS106L learning repo
notes: add lecture 01 welcome summary
experiments: test auto and type deduction
assignments: start hashmap writeup
```
