## How I Use This Repo

For each lecture, I keep:

- A short English/Chinese summary.
- Key C++ concepts.
- Questions I asked while reading the slides.
- Code snippets or experiments that clarify the idea.
- A final "what I can explain now" checklist.

When I get stuck, I record the question first, then update the answer after I understand it. That way the repo captures the learning process, not only polished conclusions.
